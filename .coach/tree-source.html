Árvore de Padrões LeetCode

Todo problema se reduz a uma estrutura de dados + uma operação que preserva um invariante. Responda às perguntas sobre o enunciado e a árvore te leva ao padrão, com os sinais que o denunciam, o template e os clássicos para treinar.

Siglas: DP = programação dinâmica (tabela de subproblemas). Não confunda com dois ponteiros (two pointers), que são dois índices andando pelo array. Aqui a árvore sempre escreve os dois nomes por extenso.

Passo 0: leia os constraints antes do enunciado

Régua: ~10⁸ operações simples por segundo
n ≤ 11O(n!)Permutações, backtracking puro
n ≤ 25O(2ⁿ)Subconjuntos, bitmask, backtracking
n ≤ 500O(n³)Prog. dinâmica intervalar, Floyd-Warshall
n ≤ 10⁴O(n²)Prog. dinâmica 2D, todos os pares
n ≤ 5·10⁶O(n log n)Sort, heap, binary search, hash. Com constantes, 10⁶ é o teto seguro
n ≤ 10⁸O(n)Uma passada: janela, dois ponteiros, prefixo, pilha
n ≥ 10⁹O(log n)Binary search na resposta, matemática

Como derivar a tabela: o orçamento é ~10⁸. Resolva f(n) = 10⁸ para o n máximo. Em n², n = √10⁸ = 10⁴. Em n³, n = ∛10⁸ ≈ 500. Em n log n, log₂ n ≈ 22, então n ≈ 10⁸ / 22 ≈ 5·10⁶.

Exemplo de uso: com n = 10⁵, n² = 10¹⁰ estoura o orçamento e n log n ≈ 1,7·10⁶ cabe. Sobram O(n log n) e O(n).
